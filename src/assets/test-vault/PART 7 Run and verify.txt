# PART 7 — Run and verify - VAULT

```bash
npm run tauri dev
```

**Prerequisites:** OpenAI key added in Settings (you can use the same key with ~$5 credit on OpenAI's platform).

**Verification checklist:**

1. ☐ App launches with no errors.
2. ☐ Click "Vault" in nav → page loads with empty Sources panel and Search panel.
3. ☐ Click ADD FOLDER → OS file picker opens → select a small test folder (~5-20 markdown files; create one if you don't have an Obsidian vault: `mkdir ~/test-vault && echo "# Note one\n\nThis is the first note." > ~/test-vault/one.md`).
4. ☐ Source appears in list with 0 files, 0 chunks, "never synced".
5. ☐ Click SYNC. Progress bar appears, ticks file by file.
6. ☐ On completion: file count and chunk count update. "synced" timestamp shows current time.
7. ☐ Verify DB:
   
   ```bash
   DB=$(find ~ -name "axisai.db" 2>/dev/null | head -1)
   sqlite3 "$DB" "SELECT COUNT(*) FROM vault_chunks WHERE owner_id IN (SELECT id FROM owners);"
   sqlite3 "$DB" "SELECT source_path, chunk_index, heading, substr(content, 1, 60) FROM vault_chunks LIMIT 5;"
   ```
   Rows exist with real content excerpts and headings.
8. ☐ **Embedding column is JSON-encoded floats, length 1536**:
   ```bash
   sqlite3 "$DB" "SELECT length(embedding), embedding_model FROM vault_chunks LIMIT 1;"
   ```
   First value should be ~20000+ chars (JSON of 1536 floats); model should be `text-embedding-3-small`.
9. ☐ MTD counter in Test Call panel (Settings) reflects the embedding cost (~$0.0001 for a small vault).
10. ☐ In Vault Search panel, type a query relevant to your notes' content. Click SEARCH.
11. ☐ Within 1-2s, 5 result cards appear with: file path, heading, content excerpt, similarity score (top result usually 30-80%).
12. ☐ Delete the source (trash icon). Source disappears AND chunks are gone:
    ```bash
    sqlite3 "$DB" "SELECT COUNT(*) FROM vault_chunks;"
    ```
    Returns 0.

If all 12 pass, **Vault is done**.

# PART 8 — Module boundary self-check

- ☐ Vault imports only from `../core`, `../settings`, `../router` (via their index files).
- ☐ `searchSimilar` is the only retrieval entry point exposed; embedding internals (`cosineSimilarity`, raw OpenAI HTTP) are private to the module.
- ☐ OpenAI HTTP call appears only in `src/modules/vault/embeddings.ts`. No other file touches `api.openai.com`.
- ☐ Embedding costs logged through Router's `logCall` (same MTD bucket as chat calls).
- ☐ Raw note content never appears in `router_calls` table — only metadata.
